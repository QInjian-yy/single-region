# AEM=0.02 Whole Bag 的三组五折消融

归档日期为 2026-11-18。原 Whole Bag 基线的五折 Test AUC 为 **0.7547 ± 0.0771**，高于关闭 Label Smoothing、Head LR 减半和 Global MHSA 三组。Head LR 减半在各折保存的验证阈值下取得最高 Test BACC，主要来自更少的正常切片误报。

## 实验设置

五组均使用 Seed123 的 CAMELYON16 五折划分。训练 seed 为 1，输入是一张 WSI 的完整 Region 集合。模型以共享 ResNet18 编码 LR512 和每个 Region 的两个 HR256 图块，用 Attention MIL 聚合。AEM 从 0.02 起按 50 轮余弦退火，EMA 为 0.999，SR 为 0，优化器为 AdamW，精度为 BF16。

| 实验 | 对应折 YAML 相对基线的改动 |
| --- | --- |
| [Whole Bag 基线](../s123_aem02_wholebag_ssd_5fold_20261116_200914/summary.json) | Head LR = 2×10⁻⁴，Label Smoothing = 0.1 |
| [Semantic Top-K](../s123_relation_topk_5fold_20261117_110419/summary.json) | 启用 Semantic Top-K，K=3，初始有效 Gate=0.01 |
| [Global MHSA](../s123_global_mhsa_5fold_20261117_163157/summary.json) | 启用 Global MHSA，4 个头，attention dropout=0.1，初始有效 Gate=0.1 |
| [Head LR 减半](../s123_baseline_headlr_half_20261117_201754/summary.json) | `classification.head_lr` 从 2×10⁻⁴ 调到 1×10⁻⁴ |
| [关闭 Label Smoothing](../s123_baseline_ls0_20261118_005509/summary.json) | `label_smoothing` 从 0.1 调到 0 |

按当前多尺度优化器实现，`head_lr` 同时用于分类头、融合层、HR 图块评分和融合 Gate。Encoder 学习率设为 1×10⁻⁵。关闭 Label Smoothing 改变交叉熵的定义，跨组比较训练损失的绝对值缺少相同尺度。

## 五折结果

Val AUC 取各折被选中 checkpoint 的验证分数。Test AUC 为五折等权平均 ± 样本标准差。ACC、BACC（平衡准确率）、肿瘤召回率和特异度为各折等权平均，沿用在验证集上按 BACC 选定的阈值。

| 实验 | Val AUC | Test AUC | 相对基线 Δ Test AUC | Test ACC | Test BACC | 肿瘤召回率 | 特异度 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| Whole Bag 基线 | 0.7471 | 0.7547 ± 0.0771 | — | 67.94% | 65.70% | 53.75% | 77.66% |
| Semantic Top-K | 0.7414 | 0.7275 ± 0.0669 | -0.0273 | 65.92% | 65.40% | 62.50% | 68.31% |
| Global MHSA | 0.7248 | 0.7150 ± 0.0644 | -0.0398 | 65.90% | 65.29% | 61.88% | 68.70% |
| Head LR 减半 | 0.7405 | 0.7317 ± 0.0678 | -0.0230 | 71.24% | 68.09% | 51.25% | 84.92% |
| 关闭 Label Smoothing | 0.7391 | 0.7440 ± 0.0812 | -0.0107 | 69.71% | 67.41% | 55.00% | 79.81% |

- Global MHSA 的 Test AUC 在五折均低于基线和 Semantic Top-K。相对基线平均降低 0.0398，相对 Top-K 平均降低 0.0125。Fold 2 的下降最大（相对基线 −0.0874）。Fold 1 的 Val AUC 达到 0.8125，是新增三组的最高验证分数，但该折 Test AUC 为 0.6646。
- Head LR 减半在 Fold 4 提升 0.0163，其余四折 AUC 下降。Test BACC 从 65.70% 升至 68.09%，正常切片误报从 52 张减少到 35 张，肿瘤漏检从 74 张增加到 78 张。
- 关闭 Label Smoothing 的 Test AUC 在新增三组中最高，比基线低 0.0107。Fold 3 提升 0.0283，其余四折下降。该组 Test BACC 为 67.41%，五折共少 5 张正常切片误报和 2 张肿瘤漏检。

## 核验与归档

- 对照和新增实验共 25 折。重算 50 份逐张预测的 Val/Test AUC、ACC、BACC、敏感性及特异度，并从验证预测重选阈值。数值与保存记录一致，按历史重放的最佳 epoch 和早停也一致。
- 每组五折测试覆盖 393 张不同 WSI、6,531 个 Region，每张 WSI 测试一次。对应折的 Val/Test 名单、标签和 Region 数一致，且同折 Val/Test 名单无交集。五组共有的数据清单和划分哈希一致。
- 新增三组与 Semantic Top-K 使用同一份记录的 SSD LR 映射。原基线由较早的入口生成，其记录没有 SSD LR 映射字段。原始划分文件在本地缺失，实际 Train 名单和患者级独立性仍待核实。比较反映同一训练种子下的这套五折协议。
- 新增三组各保留 36 份原始记录，15 个最佳 checkpoint 权重留在本地。逐折数据和原始记录校验值见[核验 JSON](mhsa_headlr_label_smoothing_20261118.json)。
