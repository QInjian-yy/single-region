# GCSAM + AdamW / MeanMIL / SR0 / Fold 1 实验快照

本记录对应 `gcsam_f1_20261105_150932`，实验 ID 为
`EXP-20261105-151949-9f814bd5fea6`。训练设备为 NVIDIA RTX A4000，seed=1，
使用 CAMELYON16 native512 五折划分的 Fold 1。

## 运行状态与配置

当前归档有 48 个完整 epoch，日志还记录了第 49 轮的 29/211 张训练 WSI，
最后全局 iteration=10157。原始 `run_info.json` 为 `incomplete`，日志没有最终
`[run]` 标记；本次保留该状态，不将下载快照视为训练结束，也不推断服务器当前是否仍在运行。

使用预训练 ResNet18，仅微调 layer4、冻结 BN，MeanMIL，全部 Dropout=0，
VIB 关闭，SR 全程为 0，BF16，整批编码且 `max_train_regions: null`。
GCSAM 从第 1 轮启用，基础优化器为 AdamW，rho=0.05，GC 仅用于扰动方向，
在 GC 后归一化。encoder/head 初始学习率分别为 1e-5/2e-4，
weight decay=0.01、label smoothing=0.1、EMA=0.999，保留原增强、Plateau 和早停。

本次实际配置使用全部 regions；默认示例 `configs/native512_gcsam.yaml` 的
训练 region 上限为 24，两者应按各自配置区分。复现实验应使用下方归档配置。
