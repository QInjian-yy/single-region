# LR 选择器 + HR 排名注意力（Fold 0）

本组是独立单折实验，使用 CAMELYON16 Seed123 的 Fold 0 划分（Train 236 张、Val 79 张、Test 78 张）。训练共 25 轮，按 Val AUC 选择第 13 轮权重进行测试。

在 K=4 ScaleProj 的基础上，每个 region 使用 LR 选择器排出的 4 张 256×256 HR 小块。在 HR 内容注意力分数上加入一个由可学习标量控制的排名偏置，偏置从零开始。相对普通 K=4 ScaleProj 的同一折，本组的配置和划分一致，HR 缓存有所变化，因此本次结果反映 LR 选块与排名偏置的组合效果。

| 数据范围 | Test AUC | ACC | BACC | 肿瘤召回率 | 特异度 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Fold 0 | 0.9198 | 75.64% | 78.40% | 93.75% | 63.04% |

以上为 Fold 0 的结果，单独归档。原始配置、训练历史、逐张预测和数据来源见 [fold_0](fold_0)。
