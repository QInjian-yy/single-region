# LR 自动选块 + HR 排名注意力（五折）

在 CAMELYON16 的 Seed123 五折划分下，RankAttn 与直接对照 LRSelect 使用相同的训练配置、验证和测试 WSI，以及逐折相同的 HR 缓存索引。每个 Region 使用 LR 病灶选块器已有的 4 张 HR256 小块，按选块分数排序。RankAttn 在原有 HR 内容注意力分数上加上 `α × [1.5, 0.5, −0.5, −1.5]`，其中 α 是零初始化的单个可训练参数，所有 Region 共享。[LRSelect 对照](../s123_hrk4_noema_scaleproj_lrselect_5fold_20261126/summary.json)

以五折等权汇总，RankAttn 的平均 Test AUC 提高 1.17 个百分点，4 折提高，Fold 1 下降 4.49 个百分点。按各折各组在验证集上选定的阈值，RankAttn 检出的肿瘤切片更多，正常切片误报也更多。AUC 的折间标准差有所增加。
