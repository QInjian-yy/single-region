# 已知病灶位置的 K=4 HR 选块诊断（Oracle）

本组检验 **HR 小块的选取位置是否影响 WSI 分类**。五折数据划分、LR 输入、每个 region 的 HR 小块数量和尺寸、ScaleProj 模型结构及训练配置与普通选块对照一致。对照为[普通 K=4 ScaleProj](../s123_hrk4_noema_scaleproj_5fold_20261124_101720)。

每个 region 保留 4 张 256×256 的 HR 小块。对已知阳性的 WSI，使用 XML 病灶标注，优先选取与病灶重叠面积较大的小块。数量不足时沿用普通选块补齐。没有可用病灶标注或没有命中病灶的 region 沿用普通选块。

**Train、Val 和 Test 均使用这份标注引导的 HR 缓存。** 这组对照表明，改变 HR 取块位置会影响当前模型的分类表现。由于训练和评估时的取块都发生了变化，这组结果无法单独衡量仅在训练阶段使用标注的效果。**本组只作为选块诊断，单独归档，不计入第四周常规 Test 对比、最佳成绩或性能提升。**

目录保留五折原始配置、预测、指标及数据来源，供核对上述评估口径。
